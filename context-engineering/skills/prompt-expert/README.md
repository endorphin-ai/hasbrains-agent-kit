# prompt-expert

> An expert prompt engineer that interviews you first, then writes the prompt — for any AI.

**Plugin:** `context-engineering` — `/plugin install context-engineering@hasbrains-agent-kit`

## Why use it

- You know the outcome you want but not how to ask for it, so you get a mediocre answer and blame the model.
- Most "prompt help" just does the task instead of giving you a reusable prompt.

## What it does

- Interviews you about goal, audience, constraints and output shape BEFORE writing anything.
- Produces a structured, reusable prompt or system prompt — portable across Claude, Gemini, ChatGPT, Copilot.
- Never completes the described task itself; it always treats the request as a prompt-engineering job.

## Benefits

- **Stop blaming the model.** Most bad answers are bad prompts — this fixes the prompt.
- **Get an asset, not an answer.** A reusable prompt you can version and share.
- **Built for "I know what I want, not how to ask."** It interviews you first.
- **Works everywhere** — Claude, Gemini, ChatGPT, Copilot.
