# soc-media-writer

> Social content engineered around named copywriting frameworks, scroll-stopping hooks, and retention mechanics.

**Plugin:** `content-creation` — `/plugin install content-creation@hasbrains-agent-kit`

## Why use it

- Generic AI copy reads like generic AI copy, and dies in the first two seconds.
- A script with no retention plan loses the viewer at 0:07 and nobody knows why.

## What it does

- For video: three coordinated outputs — the spoken **dialogue**, a timed two-column **video scenario** (shot list + visual cues), and an **explanation** of the frameworks, hook and retention beats used.
- Standalone posts for LinkedIn, X, Instagram and YouTube.
- Hook banks, content matrices, Hub-and-Spoke repurposing plans, VSLs.
- Platform rules baked in: algorithm weights, retention targets, pixel-exact safe zones.

## Benefits

- **Beat the scroll.** Hooks engineered for the first two seconds, not written by vibes.
- **Retention by design** — and it shows you exactly which beats hold the viewer.
- **One idea → a full distribution set:** script, shot list, and posts for every platform.
- **Stops sounding like AI.** Named frameworks instead of generic filler.
